
# DBWP.pro — WordPress Development & Support Website

**A responsive business landing page built with Next.js, React and Tailwind CSS, featuring animated content, a modal project gallery and an integrated contact form.**

DBWP.pro is a self-directed development project exploring the design and implementation of a website for an independent WordPress developer and support business.

The site brings together service information, portfolio examples and a direct enquiry form within a bold, modern interface.

Built using Next.js App Router, the project focuses on responsive design, reusable React components, interactive elements and frontend presentation.

## Key Features

### Responsive Landing Page

DBWP.pro uses a single-page layout to introduce an independent WordPress development and support service.

- Bold introductory section
- Service information and descriptions
- Responsive layouts
- Clear navigation and calls to action
- Contact and enquiry functionality

The design aims to communicate the services available without overwhelming visitors with unnecessary content.

### Interactive Project Gallery

The site includes a portfolio gallery using reusable React components.

- Project cards presenting selected work
- Modal interfaces displaying additional details
- Interactive controls for opening and closing project information
- Consistent styling across project presentations

Using reusable components allows the gallery to follow a common structure rather than creating separate page layouts for each project.

### Contact Form

A contact form provides a straightforward way for visitors to submit enquiries.

Formspree handles the form submissions, avoiding the need to develop and maintain a dedicated backend solely for contact messages.

### Animations and Interaction

The site uses Motion to introduce subtle animations and transitions.

These effects support the presentation of content while keeping the overall interface straightforward.

---

## Technical Approach

### Next.js App Router

DBWP.pro uses Next.js App Router to structure the application.

The project explores building a business website with React and Next.js rather than a traditional WordPress theme.

### Reusable React Components

The interface is divided into reusable components covering the site's main content and interactions.

The project gallery is a particular example, using a common modal interface to present different portfolio items.

This approach reduces unnecessary duplication and helps maintain visual consistency.

### Tailwind CSS

Tailwind CSS provides the styling system for responsive layouts, typography and component presentation.

The site uses a distinctive visual approach with bold typography, strong contrasts and carefully spaced content.

### Contact Form Integration

Formspree provides the form submission service.

For a relatively straightforward business enquiry form, this avoids introducing an unnecessary custom API or database.

### Static Deployment

The website is designed as a static frontend, making it suitable for deployment without maintaining a dedicated application server.

The contact form uses an external service, allowing the site to provide enquiry functionality without its own backend.

## Local Development

### Requirements

- Node.js
- npm

### Installation

Clone or download the repository.

Navigate into the project directory and install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

Create a production build:

```bash
npm run build
```

The contact form may require a Formspree endpoint to be configured for your own deployment.

## Project Context

DBWP.pro was created as a proof of concept for a one-person WordPress development and support business.

The project draws on my commercial experience developing and maintaining WordPress and WooCommerce websites, while exploring how Next.js and React can be used to create an alternative frontend experience.

Its focus is on presentation, responsiveness, reusable components and providing a straightforward route for prospective customers to make an enquiry.

Unlike some of my other portfolio applications, DBWP.pro is deliberately frontend-focused rather than a database-backed full-stack system.
